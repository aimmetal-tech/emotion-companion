# Emotion Companion v0.0.1

首版中文情感陪伴模型候选，基于 Qwen2.5-7B-Instruct 的 QLoRA 最佳适配器，合并为 BF16 完整模型。

## 下载

- 完整模型（约 15GB）：<https://huggingface.co/aimmetal-tech/emotion-companion-7b/tree/v0.0.1>
- 本页附件 `emotion-companion-v0.0.1-deploy.tar.gz`：官方推理入口、配置、固定模型下载/校验工具、
  无标签自测输入、训练评估摘要及 `DEPLOY.md`。附件不包含模型权重。
- 下载后先校验同名 `.sha256`，解压后按 `DEPLOY.md` 将工程和完整模型部署到 `/root/participant`。
- GitHub Source code 附件是源码，不是参赛镜像。

## 本版结果

完成 2 轮、2150 步单卡 QLoRA 训练，选中 checkpoint-2000。128 条公开验证样本的量化适配器
快速评估：原始 JSON 合规率 100%，情绪准确率 76.56%，情绪 Macro-F1 0.6999，画像平均
Micro-F1 0.5158。相应基础模型为 48.44%、32.81%、0.1545、0.1292。

本机已完成 BF16 合并、完整模型离线重载、导出文件哈希校验，128 条提示的基础/导出 tokenizer
编码一致。官方 `start.sh`、`run_inference.py` 原样保留；部署配置默认双卡 vLLM。
